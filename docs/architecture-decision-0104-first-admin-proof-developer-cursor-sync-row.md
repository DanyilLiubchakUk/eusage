# Decision 0104: First Admin proof shows developer, Cursor budget, and sync status

## Status

Accepted

## Context

The MVP Admin proof should confirm that an admin can create a developer token, connect a desktop, and see useful synced data.

Full dashboard cards and charts are not needed before the end-to-end loop is proven.

## Decision

The first minimal Admin proof shows:

- Developer row.
- Cursor budget fields.
- Token status.
- Device sync status.

## Consequences

Admin proof covers the real setup loop.

The first admin page stays small.

Dashboard charts can come after real ingest works.

## Alternatives Considered

- Full dashboard first: more polished, but hides integration risk.
- Raw data row only: fast, but too weak for product proof.
